# JASTRO2026スケジューラー（非公式）

第39回日本放射線腫瘍学会学術大会（JASTRO2026, 2026/11/12–14）の聴講予定を組むための、参加者個人による非公式ツールです。

- 全演題をタイムテーブル／リストで表示し、☆で聴講予定、メモ、自分の発表・座長・共同演者を登録できます
- データはお使いのブラウザ内（localStorage）にのみ保存され、外部に送信されません
- 端末間の移行は「予定コード」で行います
- 演題情報は公式プログラム（PDF）から抽出したものです。最新・正確な情報は必ず公式プログラムでご確認ください

本ツールは日本放射線腫瘍学会および大会事務局とは関係ありません。
